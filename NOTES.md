## Day 1
- Learned: A pointer stores the address of a variable. &a gives the address, *p reads or changes the value at that address.
- Learned: In FreeRTOS a task is a function with an endless loop. The scheduler switches between tasks. vTaskDelay sleeps only that task, so others keep running.

## Day 2
- Learned: OR sets a bit, AND with NOT clears it, XOR toggles it. 1U << n makes a mask with only bit n on.
